# Content Directory

## Purpose

This directory is currently **unused** and serves as a placeholder.

## Note

The actual content-related files for the reader feature are located in:
- `features/reader/content/` - Contains reader-specific content utilities:
  - `api-adapter.ts` - JPDB API adapter for reader features
  - `parse.tsx` - HTML parsing utilities for reader content
  - `word.ts` - Word-related types and utilities for reader features

These files are **not browser extension content scripts**; they are part of the reader feature module.

## Future Use

If you need to add browser extension content scripts in the future, this directory would be the appropriate location for them.
